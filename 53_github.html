Push Code to GitHub

Step-by-step guide from scratch

⚡ Prerequisites

  • ✅ Git installed on your computer (download here)
  • ✅ GitHub account (sign up here)
  • ✅ A project/folder with code you want to push

1 Create a Repository on GitHub

  1. Log in to your GitHub account
  2. Click the + icon in the top-right corner → New repository
  3. Enter a Repository name (e.g., my-first-repo)
  4. (Optional) Add a description
  5. Choose Public or Private
  6. DO NOT check "Initialize this repository with a README" (since you have existing code)
  7. Click "Create repository"

2 Initialize Git in Your Local Project

Open your terminal/command prompt and navigate to your project folder:

cd path/to/your/project

Initialize Git in this folder:

git init

3 Add Your Files to Staging

Add all files to be tracked:

git add .

Or add specific files:

git add filename1 filename2

4 Commit Your Files

Create your first commit with a message:

git commit -m "Initial commit"

5 Link Your Local Repo to GitHub

Copy the remote URL from your GitHub repository (you'll see it on the repo page):

git remote add origin https://github.com/your-username/repo-name.git

OR if using SSH:

git remote add origin git@github.com:your-username/repo-name.git

6 Push Your Code to GitHub

Push your code to the main branch:

git push -u origin main
💡 Note: If your default branch is master instead of main, use:
git push -u origin master

📦 Complete Example (All Commands Together)

# Navigate to your project
cd ~/Desktop/my-project

# Initialize Git
git init

# Add all files
git add .

# Commit
git commit -m "Initial commit"

# Add remote (replace with your URL)
git remote add origin https://github.com/your-username/my-first-repo.git

# Push
git push -u origin main

⚠️ Common Issues & Solutions

❌ Error: "failed to push some refs"
The remote repository has files your local doesn't. Fix with:
git pull origin main --allow-unrelated-histories
git push origin main
❌ Authentication Error
GitHub no longer accepts passwords. Use a Personal Access Token:
  1. Go to GitHub Settings → Developer settings → Personal access tokens → Generate new token
  2. Use token as password when prompted
❌ Branch Name Mismatch
If your local branch is master but remote uses main:
git branch -M main
git push -u origin main

⚡ Quick Push After Changes

Once everything is set up, future pushes are just:

git add .
git commit -m "Your message here"
git push
✅ Done! Your code should now be on GitHub. Refresh your repository page to see it.
