🔔 The 68‑95‑99.7 rule (Empirical Rule)

  • 68% within ±1σ
  • 95% within ±2σ
  • 99.7% within ±3σ
⚡ For normal (bell‑shaped) data
📈 Pros, Cons & Machine Learning Use Cases – why these statistics matter in AI

✅ Pros

  • ✓ Simple & interpretable – easy to explain to non‑technical stakeholders.
  • ✓ Efficient – O(n) computation, works on large datasets.
  • ✓ Foundation for advanced stats – used in z‑scores, confidence intervals, and hypothesis testing.
  • ✓ Standardized – universally understood across fields.

❌ Cons

  • ✗ Extremely sensitive to outliers – a single extreme value can skew both mean and SD.
  • ✗ Assumes symmetry – works best for normal distributions; misleading for skewed data.
  • ✗ Doesnʼt capture shape – different datasets can have same mean/SD but very different distributions (Anscombeʼs quartet).
  • ✗ Not robust – median and IQR are better choices for skewed or outlier‑heavy data.

🤖 Where itʼs used in Machine Learning

  • Feature Scaling Standardization (Z‑score) – subtract mean, divide by SD to center features (used in SVM, logistic regression, neural nets).
  • Outlier Detection Points beyond 2–3 SDs from the mean are often flagged as anomalies (e.g., fraud detection).
  • Loss Functions Mean Squared Error (MSE) – the standard deviation of residuals measures model performance.
  • Data Normalization Images, text embeddings, and sensor data are normalized using mean/SD for stable training.
  • Statistical Tests Used in A/B testing, feature selection (t‑tests, ANOVA), and evaluating model significance.
  • Ensemble Methods Gradient boosting uses mean/SD to compute impurity reductions and feature importance.

🐍 Python code: compute mean, SD, and plot

Run this code in your local environment (Jupyter, VS Code, or any Python 3.8+ interpreter) to generate the same visualizations and verify the calculations.

📄 mean_std_demo.py 
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

# ---------- 1. Generate data ----------
np.random.seed(42)
MEAN = 50
N = 600

# Dataset A: Low standard deviation (tight)
low_sd = 5
data_low = np.random.normal(MEAN, low_sd, N)

# Dataset B: High standard deviation (spread)
high_sd = 6   # change this value to see the effect
data_high = np.random.normal(MEAN, high_sd, N)

# ---------- 2. Compute mean & standard deviation ----------
def mean(arr):
    return sum(arr) / len(arr)

def std_pop(arr):
    m = mean(arr)
    return np.sqrt(sum((x - m) ** 2 for x in arr) / len(arr))

mean_low = mean(data_low)
sd_low = std_pop(data_low)
mean_high = mean(data_high)
sd_high = std_pop(data_high)

print(f"Low SD  → mean = {mean_low:.2f},  SD = {sd_low:.2f}")
print(f"High SD → mean = {mean_high:.2f},  SD = {sd_high:.2f}")

# ---------- 3. Plot side-by-side histograms ----------
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4))

ax1.hist(data_low, bins=20, color='#3b82f6', alpha=0.7, edgecolor='black')
ax1.axvline(mean_low, color='red', linestyle='dashed', linewidth=2,
            label=f'mean = {mean_low:.1f}')
ax1.set_title(f'Low SD = {sd_low:.2f}')
ax1.set_xlabel('Values')
ax1.set_ylabel('Frequency')
ax1.legend()

ax2.hist(data_high, bins=20, color='#ef4444', alpha=0.7, edgecolor='black')
ax2.axvline(mean_high, color='red', linestyle='dashed', linewidth=2,
            label=f'mean = {mean_high:.1f}')
ax2.set_title(f'High SD = {sd_high:.2f}')
ax2.set_xlabel('Values')
ax2.set_ylabel('Frequency')
ax2.legend()

plt.suptitle('Same Mean (50) – Different Standard Deviations', fontsize=14)
plt.tight_layout()
plt.show()

# ---------- 4. Overlapping density plots ----------
plt.figure(figsize=(10, 5))
plt.hist(data_low, bins=30, density=True, alpha=0.5, color='blue', label=f'Low SD = {sd_low:.2f}')
plt.hist(data_high, bins=30, density=True, alpha=0.5, color='red', label=f'High SD = {sd_high:.2f}')
plt.axvline(MEAN, color='black', linestyle='dashed', linewidth=1, alpha=0.6, label='Mean = 50')
plt.title('Overlapping Distributions: Narrow vs Wide')
plt.xlabel('Values')
plt.ylabel('Density')
plt.legend()
plt.grid(alpha=0.2)
plt.show()

# ---------- 5. 68-95-99.7 rule (bell curve) ----------
x = np.linspace(-4, 4, 500)
y = norm.pdf(x, 0, 1)

plt.figure(figsize=(10, 5))
plt.plot(x, y, color='black', linewidth=2.5, label='Bell curve')

# Shade the regions
colors = ['#b3d9ff', '#a3e4a3', '#f7b3b3']
labels = ['68% within ±1σ', '95% within ±2σ', '99.7% within ±3σ']
for k, color in zip([1, 2, 3], colors):
    x_fill = np.linspace(-k, k, 300)
    y_fill = norm.pdf(x_fill, 0, 1)
    plt.fill_between(x_fill, y_fill, color=color, alpha=0.5, label=labels[k-1])

plt.xticks([-3, -2, -1, 0, 1, 2, 3], ['-3σ', '-2σ', '-1σ', 'μ', '+1σ', '+2σ', '+3σ'])
plt.title('The 68-95-99.7 Rule (Empirical Rule)')
plt.xlabel('Standard deviations from the mean')
plt.ylabel('Probability density')
plt.legend()
plt.grid(alpha=0.15)
plt.show()
