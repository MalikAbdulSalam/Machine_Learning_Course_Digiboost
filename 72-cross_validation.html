Cross-Validation in Machine Learning

1. What is Cross-Validation?

Cross-Validation is a technique used in Machine Learning to evaluate how well a model performs on unseen data.

Instead of training and testing the model using only one train-test split, Cross-Validation divides the dataset into multiple parts called folds.

Simple Definition:
Cross-Validation repeatedly trains and validates a model using different portions of the dataset and then calculates the average performance.

2. Why Do We Need Cross-Validation?

Suppose we have 1,000 records.

Dataset Records
Training Data 800
Testing Data 200

If the model gets 95% accuracy, that accuracy depends on the particular 200 records selected for testing.

Cross-Validation allows us to test the model on different portions of the dataset.

Main Benefit: Cross-Validation gives us a more reliable estimate of model performance.

3. K-Fold Cross-Validation

K-Fold Cross-Validation is one of the most commonly used Cross-Validation techniques.

If we choose: 

K = 5

the dataset is divided into 5 folds.

Example

Fold 1 → Validation
Fold 2 → Training
Fold 3 → Training
Fold 4 → Training
Fold 5 → Training

In the first round, Fold 1 is used for validation and the remaining four folds are used for training.

4. Five-Fold Cross-Validation Process

Round Training Folds Validation Fold
1 2, 3, 4, 5 1
2 1, 3, 4, 5 2
3 1, 2, 4, 5 3
4 1, 2, 3, 5 4
5 1, 2, 3, 4 5

5. Calculating the Average Score

Suppose the model produces the following accuracy scores: 


Fold 1 = 91%
Fold 2 = 94%
Fold 3 = 90%
Fold 4 = 93%
Fold 5 = 92%
Average Accuracy = (91 + 94 + 90 + 93 + 92) / 5 = 92%

Therefore, the estimated model performance is approximately 92%.

6. Python Implementation

We can implement Cross-Validation using scikit-learn.

Step 1: Import Libraries


from sklearn.datasets import load_iris
from sklearn.model_selection import KFold
from sklearn.model_selection import cross_val_score
from sklearn.linear_model import LogisticRegression

Step 2: Load Dataset


X, y = load_iris(return_X_y=True)

Here:

  • X = input features
  • y = target variable

Step 3: Create Machine Learning Model


model = LogisticRegression(max_iter=200)

Step 4: Create K-Fold Object


kf = KFold(
    n_splits=5,
    shuffle=True,
    random_state=42
)

Here:

  • n_splits=5 → use 5 folds
  • shuffle=True → shuffle the dataset
  • random_state=42 → make the split reproducible

Step 5: Perform Cross-Validation


scores = cross_val_score(
    model,
    X,
    y,
    cv=kf,
    scoring="accuracy"
)

Step 6: Display Results


print("Scores:", scores)
print("Average Accuracy:", scores.mean())

Complete Python Program


from sklearn.datasets import load_iris
from sklearn.model_selection import KFold, cross_val_score
from sklearn.linear_model import LogisticRegression

# Load dataset
X, y = load_iris(return_X_y=True)

# Create model
model = LogisticRegression(max_iter=200)

# Create 5-Fold Cross-Validation
kf = KFold(
    n_splits=5,
    shuffle=True,
    random_state=42
)

# Perform Cross-Validation
scores = cross_val_score(
    model,
    X,
    y,
    cv=kf,
    scoring="accuracy"
)

# Display results
print("Fold Scores:", scores)
print("Average Accuracy:", scores.mean())

8. Stratified K-Fold Cross-Validation

For classification problems, StratifiedKFold is often preferred.

Stratified K-Fold tries to maintain approximately the same class distribution in every fold.

Example


from sklearn.model_selection import StratifiedKFold
from sklearn.model_selection import cross_val_score

skf = StratifiedKFold(
    n_splits=5,
    shuffle=True,
    random_state=42
)

scores = cross_val_score(
    model,
    X,
    y,
    cv=skf,
    scoring="accuracy"
)

print("Scores:", scores)
print("Mean Accuracy:", scores.mean())

10. Leave-One-Out Cross-Validation

Leave-One-Out Cross-Validation (LOOCV) uses one observation as validation data and all remaining observations as training data.

For example, if we have 5 records: 


Round 1 → Test Record 1
Round 2 → Test Record 2
Round 3 → Test Record 3
Round 4 → Test Record 4
Round 5 → Test Record 5

The model is therefore trained and tested once for every observation.

11. Leave-One-Out Python Example


from sklearn.model_selection import LeaveOneOut
from sklearn.model_selection import cross_val_score
from sklearn.linear_model import LogisticRegression

loo = LeaveOneOut()

model = LogisticRegression(max_iter=200)

scores = cross_val_score(
    model,
    X,
    y,
    cv=loo,
    scoring="accuracy"
)

print("Average Accuracy:", scores.mean())
Note: LOOCV can become computationally expensive for large datasets because the model may need to be trained many times.

12. Repeated K-Fold Cross-Validation

Repeated K-Fold performs K-Fold Cross-Validation multiple times using different random splits. 


from sklearn.model_selection import RepeatedKFold
from sklearn.model_selection import cross_val_score

rkf = RepeatedKFold(
    n_splits=5,
    n_repeats=3,
    random_state=42
)

scores = cross_val_score(
    model,
    X,
    y,
    cv=rkf,
    scoring="accuracy"
)

print("Number of scores:", len(scores))
print("Average Accuracy:", scores.mean())

13. Cross-Validation for Regression

Cross-Validation can also be used with regression models. 


from sklearn.datasets import load_diabetes
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import KFold
from sklearn.model_selection import cross_val_score

# Load regression dataset
X, y = load_diabetes(return_X_y=True)

# Create model
model = LinearRegression()

# Create KFold
kf = KFold(
    n_splits=5,
    shuffle=True,
    random_state=42
)

# Perform Cross-Validation
scores = cross_val_score(
    model,
    X,
    y,
    cv=kf,
    scoring="r2"
)

print("R2 Scores:", scores)
print("Average R2:", scores.mean())

15. Cross-Validation and Overfitting

Cross-Validation is useful for detecting whether a model is overfitting.

Suppose we get: 


Training Accuracy = 99%
Cross-Validation Accuracy = 72%

This large difference may indicate that the model is overfitting.

The model performs extremely well on training data but performs considerably worse on unseen data.

16. Cross-Validation for Model Comparison

Cross-Validation can be used to compare different models. 


from sklearn.model_selection import cross_val_score
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.neighbors import KNeighborsClassifier

models = {
    "Logistic Regression": LogisticRegression(max_iter=200),
    "Decision Tree": DecisionTreeClassifier(random_state=42),
    "KNN": KNeighborsClassifier()
}

for name, model in models.items():

    scores = cross_val_score(
        model,
        X,
        y,
        cv=5,
        scoring="accuracy"
    )

    print(name)
    print("Scores:", scores)
    print("Average:", scores.mean())
    print()

The model with the best average Cross-Validation score may be selected for further evaluation.

17. Important: Cross-Validation vs Test Set

Cross-Validation does not mean that we should completely eliminate a final test set.

A common workflow is: 


Complete Dataset
       |
       v
+----------------------+
| Training Data        |
|                      |
| Cross-Validation     |
+----------------------+
       |
       v
Select / Tune Model
       |
       v
Final Test Set
       |
       v
Final Performance

The final test set should ideally remain untouched until the final evaluation.

18. Common Cross-Validation Techniques

Technique Description
K-Fold Divides data into K folds.
Stratified K-Fold Maintains class distribution.
Leave-One-Out Uses one sample for validation at a time.
Repeated K-Fold Repeats K-Fold multiple times.
Time Series Split Designed for time-dependent data.

19. Key Points to Remember

  • Cross-Validation evaluates model generalization.
  • K-Fold is one of the most commonly used techniques.
  • In 5-Fold CV, the model is trained 5 times.
  • Each fold becomes validation data once.
  • The scores are usually averaged.
  • StratifiedKFold is useful for classification.
  • LOOCV uses one observation for validation at a time.
  • Cross-Validation can help identify overfitting.
  • Cross-Validation can help compare different models.
  • A separate final test set is still useful for unbiased final evaluation.

20. Simple Definition for Students

Cross-Validation is a technique where the dataset is divided into multiple parts, the model is trained and validated multiple times using different parts, and the results are averaged to estimate how well the model will perform on unseen data.
