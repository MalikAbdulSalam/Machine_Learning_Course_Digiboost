Machine Learning Evaluation Metrics (Simple Explanation)

Metric Simple Meaning Better Value
MAE Average mistake Smaller ✅
MSE Average mistake, but big mistakes count much more Smaller ✅
RMSE Average mistake (easy to understand) Smaller ✅
R² How good the model is Bigger (Closer to 1) ✅
Accuracy How many answers are correct Bigger ✅
Precision When the model says "Yes", how often is it correct? Bigger ✅
Recall How many real "Yes" cases the model found Bigger ✅
F1 Score Balance of Precision and Recall Bigger ✅

Example 1: House Price Prediction (Regression)

Actual House Price = 100
Predicted Price = 90
Mistake = 10

MAE: Average mistake is 10

MSE: Squares the mistake.
10² = 100

RMSE: Square root of MSE.
√100 = 10

R²: If R² = 0.95, the model is about 95% good.

Example 2: Cat vs Dog Classification

There are 100 pictures.
The model correctly predicts 95.

Accuracy = 95%

Meaning:
The model got 95 out of 100 predictions correct.

Precision

The model predicts 20 pictures are Cats.

  • 18 are actually Cats ✅
  • 2 are Dogs ❌
Precision = 18 / 20 = 90%

Meaning:
Whenever the model says "Cat", it is correct 90% of the time.

Recall

There are actually 25 Cat pictures. The model finds only 20.

Recall = 20 / 25 = 80%

Meaning:
The model found 80% of all the real Cat pictures.

F1 Score

Precision = 90%
Recall = 80%

F1 Score ≈ 85%

Meaning:
One score that measures how good both Precision and Recall are together.

Easy Memory Trick 🧠

MAE = Average Error

MSE = Big Errors Matter More

RMSE = Average Error (Easy to Understand)

R² = How Good the Model Is

Accuracy = How Many Correct

Precision = When Model Says "Yes", Is It Right?

Recall = Did It Find All the Real "Yes" Cases?

F1 Score = Balance of Precision and Recall

One-Line Summary

  • Regression (Predict Numbers): MAE, MSE, RMSE, R²
  • Classification (Predict Classes): Accuracy, Precision, Recall, F1 Score
