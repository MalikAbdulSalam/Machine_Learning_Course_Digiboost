🧠 overfitting · underfitting

machine learning · bias–variance tradeoff
📘 study analogy: underfit = barely study · overfit = memorize

⬇️ underfitting high bias

✖ too simple · fails to capture pattern. High error on both training & test.

📊 training error high 📉 test error high 🧩 model complexity low
📐 actual trend (curve) ● training points
━━━ underfit (straight line) → misses curve
⚙️ causes
  • model too simple (e.g. linear for nonlinear data)
  • too few features / wrong features
  • excessive regularization (λ too high)
  • insufficient training time
🔧 fixes
  • increase model complexity (add layers, polynomial features)
  • add relevant features
  • train longer / reduce regularization

⬆️ overfitting high variance

✖ too complex · memorizes noise. Very low training error, high test error.

📊 training error very low 📉 test error high 🧩 model complexity high
📐 true pattern (smooth) ● training points
﹏﹏ overfit (wiggly) → passes through every point
⚙️ causes
  • model too complex (too many parameters)
  • too little training data
  • training too many epochs
  • no regularization
🔧 fixes
  • collect more training data
  • regularization (L1/L2, dropout)
  • early stopping
  • reduce model complexity
  • cross-validation
