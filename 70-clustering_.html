10 More Clustering Algorithms in Python

This lesson covers ten additional clustering algorithms that can be implemented using Python.

1. Install Required Libraries

pip install numpy pandas matplotlib scikit-learn scipy

Some algorithms require additional libraries. 

pip install scikit-fuzzy
pip install scikit-learn-extra
pip install hdbscan

2. Create a Dataset

import numpy as np
import matplotlib.pyplot as plt

from sklearn.datasets import make_blobs

# Create artificial dataset

X, y = make_blobs(
    n_samples=500,
    centers=4,
    cluster_std=1.2,
    random_state=42
)

print(X.shape)

3. Mean Shift Clustering

Mean Shift identifies dense regions in the dataset and moves points toward the centers of those dense regions.

Main advantage:

You do not need to specify the number of clusters beforehand. 

from sklearn.cluster import MeanShift

# Create model

model = MeanShift()

# Train and predict

labels = model.fit_predict(X)

print("Cluster Labels:")
print(labels)

print("Number of clusters:")
print(len(np.unique(labels)))

Visualization

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=labels
)

plt.title("Mean Shift Clustering")

plt.xlabel("Feature 1")
plt.ylabel("Feature 2")

plt.show()

4. Spectral Clustering

Spectral Clustering uses relationships and similarities between data points. 

from sklearn.cluster import SpectralClustering

model = SpectralClustering(
    n_clusters=4,
    affinity="nearest_neighbors",
    random_state=42
)

labels = model.fit_predict(X)

print(labels)

Visualization

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=labels
)

plt.title("Spectral Clustering")

plt.show()

5. BIRCH Clustering

BIRCH stands for Balanced Iterative Reducing and Clustering using Hierarchies.

It is designed to work efficiently with large datasets. 

from sklearn.cluster import Birch

model = Birch(
    n_clusters=4
)

labels = model.fit_predict(X)

print(labels)

Visualization

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=labels
)

plt.title("BIRCH Clustering")

plt.show()

6. Affinity Propagation

Affinity Propagation identifies representative data points called exemplars.

You do not have to directly specify the number of clusters. 

from sklearn.cluster import AffinityPropagation

model = AffinityPropagation(
    random_state=42
)

labels = model.fit_predict(X)

print(labels)

print(
    "Number of clusters:",
    len(np.unique(labels))
)

Visualization

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=labels
)

plt.title("Affinity Propagation")

plt.show()

7. OPTICS

OPTICS stands for Ordering Points To Identify the Clustering Structure.

It is a density-based algorithm related to DBSCAN. It can handle clusters with different densities. 

from sklearn.cluster import OPTICS

model = OPTICS(
    min_samples=10,
    xi=0.05,
    min_cluster_size=0.05
)

labels = model.fit_predict(X)

print(labels)

Visualization

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=labels
)

plt.title("OPTICS Clustering")

plt.show()

8. Mini-Batch K-Means

Mini-Batch K-Means is a faster variation of K-Means.

Instead of processing the entire dataset during every iteration, it uses small batches of data. 

from sklearn.cluster import MiniBatchKMeans

model = MiniBatchKMeans(
    n_clusters=4,
    batch_size=50,
    random_state=42,
    n_init=10
)

labels = model.fit_predict(X)

print(labels)

Visualization

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=labels
)

plt.title("Mini-Batch K-Means")

plt.show()

9. Fuzzy C-Means

Fuzzy C-Means is different from traditional clustering.

A data point can partially belong to multiple clusters.

For example: 

Customer A

Cluster 1 → 0.80
Cluster 2 → 0.15
Cluster 3 → 0.05

This means the customer has an 80% membership in Cluster 1.

Python Implementation

import skfuzzy as fuzz

# Transpose data
data = X.T

# Apply Fuzzy C-Means

centers, membership, _, _, _, _, _ = fuzz.cluster.cmeans(
    data,
    c=4,
    m=2,
    error=0.005,
    maxiter=1000,
    init=None
)

# Get cluster with highest membership

labels = np.argmax(
    membership,
    axis=0
)

print(labels)

Visualization

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=labels
)

plt.title("Fuzzy C-Means")

plt.show()

10. K-Medoids

K-Medoids is similar to K-Means.

However, instead of using the mathematical mean as the center, it uses an actual data point as the center.

K-Means:

Cluster center = calculated average

K-Medoids:

Cluster center = actual data point 

from sklearn_extra.cluster import KMedoids

model = KMedoids(
    n_clusters=4,
    random_state=42
)

labels = model.fit_predict(X)

print(labels)

Visualization

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=labels
)

# Plot medoids

medoids = model.cluster_centers_

plt.scatter(
    medoids[:, 0],
    medoids[:, 1],
    marker="X",
    s=200
)

plt.title("K-Medoids")

plt.show()

11. HDBSCAN

HDBSCAN is an advanced density-based clustering algorithm.

It is related to DBSCAN but can handle clusters with different densities more effectively. 

import hdbscan

model = hdbscan.HDBSCAN(

labels = model.fit_predict(X)

Visualization

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=labels
)

plt.title("HDBSCAN Clustering")

plt.show()

12. Self-Organizing Map (SOM)

A Self-Organizing Map is a neural-network-based technique that can be used for clustering and dimensionality reduction.

SOM is not included directly in scikit-learn, so we can use the MiniSom library.

Install MiniSom

pip install minisom

Python Implementation

from minisom import MiniSom

# Create SOM

som = MiniSom(
    5,
    5,
    X.shape[1],
    sigma=1.0,
    learning_rate=0.5,
    random_seed=42
)

# Initialize weights

som.random_weights_init(X)

# Train SOM

som.train_random(
    X,
    1000
)

print("SOM training completed.")

Find the Winning Neuron

for point in X:

    winner = som.winner(point)

    print(
        "Data point:",
        point,
        "Winner:",
        winner
    )

Fuzzy C-Means Fuzzy clustering Yes

SOM Neural-network-based Grid-based

14. Summary

Mean Shift → Finds dense regions automatically.

Spectral Clustering → Uses relationships between data points.

BIRCH → Efficient for large datasets.

Affinity Propagation → Finds representative examples.

OPTICS → Density-based clustering with varying density.

Mini-Batch K-Means → Faster K-Means for large datasets.

Fuzzy C-Means → Points can partially belong to multiple clusters.

K-Medoids → Uses actual data points as cluster centers.

HDBSCAN → Advanced density-based clustering.

SOM → Neural-network-based clustering and visualization.
