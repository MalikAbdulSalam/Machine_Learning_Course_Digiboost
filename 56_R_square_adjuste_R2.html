📊 R² vs Adjusted R² with Multiple Features

Learning Goal: Understand how R² and Adjusted R² work when a Linear Regression model contains multiple features.

1. What is a Feature?

A feature is an input variable that we use to predict the target variable.

For example, suppose we want to predict house prices:

SizeBedroomsAgeDistancePrice
1200352.1250
1500431.5320
9002105.0180
1800421.0400
1100383.5220
Features (X): Size, Bedrooms, Age, Distance
Target (Y): Price

2. Multiple Features

When we have more than one feature, we use Multiple Linear Regression.

X = df[["Size", "Bedrooms", "Age", "Distance"]]
y = df["Price"]

Here we have 4 features.

k = X.shape[1]

The value of k will be:

k = 4

3. R² with Multiple Features

R² tells us how much of the variation in the target variable is explained by the complete model.

Important: R² is calculated for the entire model, not separately for each feature. 
r2 = r2_score(y, y_pred)

If:

R² = 0.85

it means the model explains approximately 85% of the variation in the target.

4. Adjusted R² with Multiple Features

Adjusted R² considers both the model's R² and the number of features used by the model.

Adjusted R² = 1 − (1 − R²) × (n − 1) / (n − k − 1)

Where:

  • n = number of observations
  • k = number of features
  • R² = R-Squared

Python can automatically determine the number of features:

n = len(y)
k = X.shape[1]

5. Complete Python Example

import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# Dataset
data = {
    "Size": [1200, 1500, 900, 1800, 1100],
    "Bedrooms": [3, 4, 2, 4, 3],
    "Age": [5, 3, 10, 2, 8],
    "Distance": [2.1, 1.5, 5.0, 1.0, 3.5],
    "Price": [250, 320, 180, 400, 220]
}
df = pd.DataFrame(data)

# Features
X = df[["Size", "Bedrooms", "Age", "Distance"]]
# Target
y = df["Price"]

# Create model
model = LinearRegression()
# Train model
model.fit(X, y)
# Predictions
y_pred = model.predict(X)

# R²
r2 = r2_score(y, y_pred)

# Number of observations
n = len(y)
# Number of features
k = X.shape[1]

# Adjusted R²
adjusted_r2 = 1 - (1 - r2) * (n - 1) / (n - k - 1)

print("Number of observations:", n)
print("Number of features:", k)
print("R²:", r2)
print("Adjusted R²:", adjusted_r2)

6. Do We Calculate R² for Every Feature?

No. You normally calculate R² for the complete regression model.

For example:

X = df[["Size", "Bedrooms", "Age", "Distance"]]

This creates one model using all four features. The resulting R² represents the performance of that complete model.

❓ Questions & Answers

Q1. What does R² tell us about a regression model?
Answer: R² (the coefficient of determination) tells us the proportion of variance in the target variable that is explained by the independent variables in the model. It ranges from 0 to 1, where 1 means the model explains all the variability, and 0 means it explains none.
Q2. What happens to R² when more features are added?
Answer: R² never decreases when more features are added — it either stays the same or increases. This is because adding more predictors allows the model to fit the training data at least as well, even if the new features are completely irrelevant.
Q3. Why can R² be misleading when many features are added?
Answer: R² can be misleading because it will keep increasing (or stay the same) as you add more features, even if those features have no real predictive power. This can lead to overfitting, where the model captures noise rather than the true underlying relationship, giving a false impression of a "better" model.
Q4. What does Adjusted R² consider that R² does not?
Answer: Adjusted R² takes into account the number of features (k) in the model and the sample size (n). It applies a penalty for adding extra predictors, so it only increases if the new feature actually improves the model more than would be expected by chance.
Q5. What is k in the Adjusted R² formula?
Answer: In the Adjusted R² formula, k is the number of independent features (predictors) used in the regression model. It is used in the penalty term: 1 − (1 − R²) × (n − 1) / (n − k − 1).
Q6. What does X.shape[1] return?
Answer: In Python (with pandas or NumPy), X.shape[1] returns the number of columns in the feature matrix X. Since each column typically represents a feature, this gives the total number of features used in the model.
Q7. Which metric is more useful when comparing models with different numbers of features?
Answer: Adjusted R² is more useful when comparing models with different numbers of features because it accounts for the number of predictors. It penalizes the addition of unnecessary features, helping you select a model that balances goodness-of-fit with simplicity (avoiding overfitting).
Q8. Can Adjusted R² decrease when a new feature is added? Explain.
Answer: Yes, Adjusted R² can decrease when a new feature is added. This happens if the new feature does not provide enough improvement in R² to offset the penalty for adding an extra predictor. In other words, if the feature adds little or no explanatory power, the adjusted metric will go down, signaling that the feature is not worth including.

🎓 Final Takeaway

R² measures how much of the target's variation is explained by the complete model.

Adjusted R² does the same thing but also considers how many features are being used.

Therefore, when comparing regression models with different numbers of features, Adjusted R² is often more useful than R² alone.
