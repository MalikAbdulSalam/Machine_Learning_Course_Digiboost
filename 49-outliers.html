Outliers in Data Preprocessing

What is an Outlier?

An outlier is a data point that is significantly different from the other observations in a dataset. It lies far away from the majority of the data. Outliers may occur because of measurement errors, data entry mistakes, equipment malfunctions, or they may represent genuine rare events.

Outliers can negatively affect machine learning models by changing the mean, increasing variance, and reducing prediction accuracy.

Example

Student Age
A 20
B 21
C 22
D 19
E 20
F 95

Here, the value 95 is an outlier because all other ages are around 19–22.

Why are Outliers Important?

  • Can reduce machine learning model accuracy.
  • Can significantly affect the mean and standard deviation.
  • Can mislead statistical analysis.
  • Can increase prediction errors.
  • Sometimes they represent valuable rare events and should not be removed.

How to Detect Outliers?

There are several statistical and visualization techniques for detecting outliers.

1. Box Plot Method (Most Popular)

A Box Plot shows the distribution of data using quartiles. Any value outside the whiskers is considered an outlier.

2. Interquartile Range (IQR) Method

IQR measures the spread of the middle 50% of data.

Formula:

IQR = Q3 - Q1

Lower Limit = Q1 - 1.5 × IQR

Upper Limit = Q3 + 1.5 × IQR

Any value below the lower limit or above the upper limit is considered an outlier.

Example

Quartile Value
Q1 20
Q3 40
IQR 20
Lower Limit -10
Upper Limit 70

Any value greater than 70 is an outlier.

3. Z-Score Method

The Z-score measures how many standard deviations a value is away from the mean.

Formula

Z = (X - Mean) / Standard Deviation

If:

  • Z > 3
  • Z < -3

then the value is usually considered an outlier.

4. Percentile Method

Values below the 1st percentile or above the 99th percentile can be treated as outliers.

5. Machine Learning Methods

  • Isolation Forest
  • DBSCAN
  • Local Outlier Factor (LOF)
  • One-Class SVM

How to Visualize Outliers?

Visualization helps us quickly identify unusual values.

1. Box Plot ⭐ (Best Method)

A box plot directly displays outliers as individual points. 

Matplotlib:

plt.boxplot(df["Salary"])
plt.show()

2. Scatter Plot

Scatter plots show points that lie far away from the majority. 

plt.scatter(df.index, df["Salary"])
plt.show()

3. Histogram

Histograms reveal extremely high or low values. 

plt.hist(df["Salary"])
plt.show()

4. Violin Plot

Shows both the distribution and potential outliers.

5. Density Plot (KDE)

Displays the probability distribution and highlights unusual values.

How to Handle Outliers?

The handling technique depends on why the outlier exists.

Situation Recommended Action
Data Entry Error Correct or Remove
Measurement Error Remove
Valid Rare Observation Keep
Extreme Value Affecting Model Cap or Transform

Method 1: Remove Outliers

Delete observations that are incorrect or significantly different from the rest. 

Remove values outside IQR limits.

Method 2: Replace with Mean or Median

Replace the outlier with the column mean or median. Median is preferred because it is less affected by extreme values.

Method 3: Winsorization (Capping)

Replace extremely high values with the maximum acceptable value and extremely low values with the minimum acceptable value.

Example: 
Original:
5, 8, 9, 10, 200

After Capping:

5, 8, 9, 10, 20

Method 4: Log Transformation

Useful for highly skewed data like salaries, house prices, population, and income.

Method 5: Robust Scaling

RobustScaler uses the median and IQR instead of the mean and standard deviation. It performs well when outliers are present.

Method 6: Keep the Outlier

Sometimes outliers are valuable.

Examples:
  • Fraud Detection
  • Disease Diagnosis
  • Earthquakes
  • Network Intrusion Detection
  • Stock Market Crashes
Removing these outliers could reduce model performance.

Advantages of Handling Outliers

  • Improves model accuracy.
  • Produces better statistical analysis.
  • Reduces prediction error.
  • Improves feature scaling.
  • Creates more reliable machine learning models.

Summary

Question Answer
What is an Outlier? An unusually large or small data value.
How to Detect? IQR, Z-Score, Percentiles, Isolation Forest.
How to Visualize? Box Plot, Scatter Plot, Histogram, Violin Plot.
How to Handle? Remove, Replace, Cap, Log Transform, Robust Scaling, or Keep.
