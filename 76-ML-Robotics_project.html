🤖 ML-Based Obstacle Avoidance Robot

Machine Learning + Robotics Project

1. Project Introduction

The ML-Based Obstacle Avoidance Robot is a robotics project in which Machine Learning is used to make decisions about how a robot should move when obstacles are present.

Instead of using traditional rule-based programming such as: 

if front_distance < 20:
    turn_left()

we train a Machine Learning model using sensor data. The trained model predicts the appropriate movement of the robot.

Main Idea:
Sensor Data → Machine Learning Model → Action → Robot Movement

2. Project Objective

The main objectives of this project are:

  • Generate or simulate robot sensor data.
  • Prepare and preprocess the dataset.
  • Train different Machine Learning classification algorithms.
  • Compare the performance of different models.
  • Use the trained model to make robot decisions.
  • Create a virtual robot simulation.
  • Implement autonomous obstacle avoidance.
  • Later transfer the system to a physical robot.

10. K-Nearest Neighbors (KNN)

KNN predicts the robot's action based on similar examples from the training dataset. 

from sklearn.neighbors import KNeighborsClassifier

model = KNeighborsClassifier(n_neighbors=5)

model.fit(X_train, y_train)

Prediction

sensor = [[80, 20, 70]]

prediction = model.predict(sensor)

print(prediction)

Possible output:

['RIGHT']

11. Decision Tree

The Decision Tree learns decision boundaries from the sensor data. 

from sklearn.tree import DecisionTreeClassifier

model = DecisionTreeClassifier()

model.fit(X_train, y_train)

12. Support Vector Machine

SVM attempts to find boundaries that separate the different robot actions. 

from sklearn.svm import SVC

model = SVC()

model.fit(X_train, y_train)

13. Random Forest

Random Forest combines multiple decision trees to produce the final prediction. 

from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier(
    n_estimators=100,
    random_state=42
)

model.fit(X_train, y_train)

16. Autonomous Simulation Loop

The robot continuously repeats the following process:

Step 1: Read virtual sensors.
Step 2: Obtain Left, Front and Right distances.
Step 3: Send sensor values to the ML model.
Step 4: Predict the robot's action.
Step 5: Move the robot.
Step 6: Update the robot position.
Step 7: Read the sensors again.
Step 8: Repeat. 
while robot_is_running:

    sensors = get_sensor_data()

    action = model.predict([sensors])

    move_robot(action)

22. Robotics Evaluation

In robotics, ML accuracy alone is not enough. We should also evaluate how well the robot actually behaves.

Metric Purpose
Accuracy How often the model predicts the correct action
F1 Score Balance between precision and recall
Collision Count Number of times robot hits an obstacle
Completion Time Time required to reach the target
Inference Time Time required to make a prediction
Successful Runs Percentage of runs completed without collision
Important: The model with the highest classification accuracy is not necessarily the best model for robotics. Speed, stability, collision rate and real-world performance are also important.
