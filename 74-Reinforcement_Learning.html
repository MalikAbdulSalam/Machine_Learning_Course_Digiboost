Tutorial : Introduction to Reinforcement Learning

1. What is Reinforcement Learning?

Reinforcement Learning (RL) is a type of Machine Learning where an agent learns by interacting with an environment.

Instead of being given the correct answer for every example, the agent receives rewards or penalties and learns which actions lead to better results.

State → Agent → Action → Environment → Reward + New State → Repeat

2. Main Components of Reinforcement Learning

Component Description Example
Agent The learner or decision maker. Robot
Environment The world where the agent operates. Maze
State The current situation. Robot at position (2,3)
Action A decision taken by the agent. Move right
Reward Feedback received after an action. +10 for reaching the goal
Policy A strategy for selecting actions. Move toward the goal
Episode One complete attempt. Start → Goal

3. Real-World Examples

  • Robot navigation
  • Self-driving vehicles
  • Game-playing AI
  • Traffic signal optimization
  • Recommendation systems
  • Resource allocation
  • Industrial control systems

4. Robot Grid Example

Suppose a robot needs to reach the goal:

S . . .
. X . .
. . . .
. . . G

S = Start
G = Goal
X = Obstacle

The robot can perform four actions:

  • Up
  • Down
  • Left
  • Right

Example reward system:

Event Reward
Reach goal +10
Hit obstacle -10
Normal step -1

5. Simple Python RL Example

import random

position = 0
goal = 4

for step in range(10):

    action = random.choice(["left", "right"])

    if action == "right":
        position += 1
    else:
        position -= 1

    position = max(0, min(position, goal))

    if position == goal:
        reward = 10
    else:
        reward = -1

    print(
        "Action:", action,
        "Position:", position,
        "Reward:", reward
    )

    if position == goal:
        print("Goal reached!")
        break
Important: This agent is currently choosing actions randomly. Reinforcement Learning algorithms will allow it to learn which actions are better.

Tutorial : Markov Decision Process (MDP) vs Hidden Markov Model (HMM)

1. What is an MDP?

A Markov Decision Process is a mathematical framework used to model sequential decision-making problems.

MDP = (S, A, P, R, γ)
Symbol Meaning
S Set of states
A Set of actions
P Transition probability
R Reward
γ Discount factor

2. Markov Property

The Markov property means that the future depends primarily on the current state rather than the complete history.

P(St+1 | St)

3. MDP Example

Consider a robot with three states: 

State 0 = Start
State 1 = Middle
State 2 = Goal

Actions:

Left
Right

Transitions:

State 0 + Right → State 1
State 1 + Right → State 2

4. Python MDP Example

states = [0, 1, 2]

actions = ["left", "right"]

rewards = {
    0: -1,
    1: -1,
    2: 10
}

state = 0

for step in range(5):

    action = "right"

    if action == "right":
        next_state = min(state + 1, 2)
    else:
        next_state = max(state - 1, 0)

    reward = rewards[next_state]

    print(
        f"State: {state}, "
        f"Action: {action}, "
        f"Next State: {next_state}, "
        f"Reward: {reward}"
    )

    state = next_state

    if state == 2:
        print("Goal reached!")
        break

5. What is an HMM?

A Hidden Markov Model is a probabilistic model where the actual state is hidden and we observe outputs generated by those hidden states.

Hidden State → Observation

6. HMM Example: Weather

Hidden states:

Sunny
Rainy

Observations:

Sunglasses
Umbrella

For example:

Rainy → Umbrella
Sunny → Sunglasses

7. Python HMM Example

states = ["Sunny", "Rainy"]

observations = {
    "Sunny": {
        "Sunglasses": 0.8,
        "Umbrella": 0.2
    },

    "Rainy": {
        "Sunglasses": 0.1,
        "Umbrella": 0.9
    }
}

observation = "Umbrella"

for state in states:

    probability = observations[state][observation]

    print(
        state,
        probability
    )

8. MDP vs HMM

Feature MDP HMM
States Usually observable Hidden
Actions Yes No decision-making actions
Rewards Yes Usually no
Main purpose Decision making State estimation / sequence modeling
Example Robot navigation Weather prediction

Consider an industrial machine. Its actual condition is hidden.

Hidden states:

Normal

Normal:
    Low vibration  = 0.9
    High vibration = 0.1

Faulty:
    Low vibration  = 0.2

probability = {

    "Normal": {
        "Low vibration": 0.9,
        "High vibration": 0.1
    },

    "Faulty": {
        "Low vibration": 0.2,
        "High vibration": 0.8

Tutorial : Bellman Equation & Q-Learning

1. Why Future Rewards Matter

An RL agent should not only consider immediate rewards. It should also consider future rewards.

Suppose:

Action A → +5 immediately

Action B → +2 immediately → +100 later

A good RL algorithm should understand that Action B may produce a larger total return.

2. Bellman Equation

V(s) = R + γV(s')
Symbol Meaning
V(s) Value of current state
R Immediate reward
γ Discount factor
V(s') Future state value

3. Bellman Numerical Example

Reward = 10
Gamma = 0.9
Future Value = 50
V(s) = 10 + (0.9 × 50) = 55

4. What is Q-Learning?

Q-Learning is an off-policy Reinforcement Learning algorithm that learns the value of taking an action in a particular state.

These values are stored in a Q-table.

State Left Right
0 0 5
1 2 10
2 1 20

At State 1: 

Q(1, Left)  = 2
Q(1, Right) = 10

Therefore, Right is currently the best action.

5. Q-Learning Formula

Q(s,a) ← Q(s,a) + α[R + γ max Q(s',a') − Q(s,a)]

6. Parameters

Parameter Meaning
α Learning rate
γ Discount factor
R Reward
Q(s,a) Current Q-value
max Q(s',a') Best future Q-value

7. Complete Q-Learning Python Example

Environment: 

0 → 1 → 2 → 3 → 4
                ↑
               Goal

Actions: 

0 = Left
1 = Right

import numpy as np
import random

# Number of states
num_states = 5

# Number of actions
num_actions = 2

# Q-table
q_table = np.zeros(
    (num_states, num_actions)
)

# Hyperparameters
learning_rate = 0.1
discount_factor = 0.9
epsilon = 0.2

episodes = 1000


for episode in range(episodes):

    state = 0

    for step in range(100):

        # Epsilon-greedy action selection
        if random.random() < epsilon:

            # Exploration
            action = random.randint(0, 1)

        else:

            # Exploitation
            action = np.argmax(
                q_table[state]
            )

        # Environment
        if action == 1:

            next_state = min(
                state + 1,
                4
            )

        else:

            next_state = max(
                state - 1,
                0
            )

        # Reward
        if next_state == 4:
            reward = 10
        else:
            reward = -1

        # Q-Learning update
        q_table[state, action] = (
            q_table[state, action]
            +
            learning_rate *
            (
                reward
                +
                discount_factor *
                np.max(
                    q_table[next_state]
                )
                -
                q_table[state, action]
            )
        )

        state = next_state

        if state == 4:
            break


print("Q-table:")
print(q_table)

8. Display Learned Policy

for state in range(num_states):

    action = np.argmax(
        q_table[state]
    )

    if action == 0:
        action_name = "Left"
    else:
        action_name = "Right"

    print(
        f"State {state}: {action_name}"
    )
Expected idea: The agent should learn that moving Right is useful because it eventually reaches the goal.

Tutorial: SARSA | On-Policy vs Off-Policy

1. What is SARSA?

SARSA is another Temporal Difference Reinforcement Learning algorithm.

The name SARSA represents:

State → Action → Reward → State → Action
  • S = Current State
  • A = Current Action
  • R = Reward
  • S = Next State
  • A = Next Action

2. SARSA Formula

Q(s,a) ← Q(s,a) + α[R + γQ(s',a') − Q(s,a)]

The important difference is that SARSA uses the actual next action selected by the agent.

3. SARSA Python Example

import numpy as np
import random

num_states = 5
num_actions = 2

q_table = np.zeros(
    (num_states, num_actions)
)

learning_rate = 0.1
discount_factor = 0.9
epsilon = 0.2

episodes = 1000


def choose_action(state):

    if random.random() < epsilon:

        # Exploration
        return random.randint(0, 1)

    # Exploitation
    return np.argmax(
        q_table[state]
    )


for episode in range(episodes):

    state = 0

    # Select first action
    action = choose_action(state)

    for step in range(100):

        # Environment
        if action == 1:

            next_state = min(
                state + 1,
                4
            )

        else:

            next_state = max(
                state - 1,
                0
            )

        # Reward
        if next_state == 4:
            reward = 10
        else:
            reward = -1

        # Goal reached
        if next_state == 4:

            q_table[state, action] += (
                learning_rate *
                (
                    reward
                    -
                    q_table[state, action]
                )
            )

            break

        # Choose next action
        next_action = choose_action(
            next_state
        )

        # SARSA update
        q_table[state, action] += (
            learning_rate *
            (
                reward
                +
                discount_factor *
                q_table[
                    next_state,
                    next_action
                ]
                -
                q_table[state, action]
            )
        )

        state = next_state
        action = next_action


print("SARSA Q-table:")
print(q_table)

4. What is On-Policy Learning?

An On-Policy algorithm learns about the same policy that it is using to make decisions.

Current Policy → Choose Action → Learn From That Action

SARSA is an example of an On-Policy algorithm.

5. What is Off-Policy Learning?

An Off-Policy algorithm can behave using one policy while learning about another policy.

Q-Learning is an example of an Off-Policy algorithm.

6. Q-Learning vs SARSA

Feature Q-Learning SARSA
Policy type Off-Policy On-Policy
Future action Best possible action Actual selected action
Formula max Q(s',a') Q(s',a')
Exploration Not directly used in target Included in actual behavior
Learning style More aggressive More conservative

7. Most Important Code Difference

Q-Learning

best_future_q = np.max(
    q_table[next_state]
)

target = (
    reward
    + gamma * best_future_q
)

SARSA

next_action = choose_action(
    next_state
)

target = (
    reward
    + gamma *
    q_table[
        next_state,
        next_action
    ]
)

8. Practical Example: Cliff Walking

Imagine the following environment: 

Start → → → → → Goal
          X X X X
          Cliff

The agent can take a safe path or move close to a dangerous cliff while exploring.

SARSA

SARSA considers the actual exploratory behavior of the agent. Because exploration can cause the agent to fall from the cliff, SARSA often learns a safer route.

Q-Learning

Q-Learning uses the maximum future Q-value and therefore focuses more directly on the optimal greedy path.
