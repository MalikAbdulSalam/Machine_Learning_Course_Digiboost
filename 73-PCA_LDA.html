Dimensionality Reduction

PCA, LDA & Kernel PCA — Complete A to Z Tutorial

1. Introduction to Dimensionality Reduction

Dimensionality reduction is the process of reducing the number of features in a dataset while trying to preserve the most important information.

Example:

100 features → 10 important components

The goal is to make the dataset smaller without losing too much useful information.
Original Dataset Feature 1 Feature 2 Feature 3 Feature 4 Feature 5 Feature 6 Feature 7 Feature 8 ↓ Dimensionality Reduction ↓ Component 1 Component 2

Why do we need dimensionality reduction?

  • Reduce computational cost
  • Remove redundant information
  • Reduce noise
  • Improve visualization
  • Sometimes improve model performance
  • Reduce the curse of dimensionality

2. Curse of Dimensionality

As the number of features increases, machine-learning algorithms can become more difficult to train and interpret.

10 features ↓ 100 features ↓ 1,000 features ↓ 10,000 features More dimensions ↓ More computation ↓ More sparse data ↓ Greater risk of overfitting
Important: Dimensionality reduction does not simply delete random columns. Techniques such as PCA create new features that are combinations of the original features.

3. Three Important Techniques

PCA No Yes Maximum variance
LDA Yes Yes Maximum class separation
Kernel PCA No Nonlinear capable Capture nonlinear structure
Dimensionality Reduction | +----------------+----------------+ | | | ↓ ↓ ↓ PCA LDA KPCA | | | Unsupervised Supervised Unsupervised | | | Linear Linear Nonlinear | | | Maximize variance Separate classes Nonlinear structure

4. PCA — Principal Component Analysis

PCA stands for Principal Component Analysis. It is one of the most widely used dimensionality-reduction techniques.

Main idea: PCA finds new directions in the data that capture the maximum amount of variance.

Example

Suppose we have five student features:

  • Math
  • Physics
  • Chemistry
  • English
  • Biology

Instead of using all five features, PCA might transform them into:

Math Physics Chemistry English Biology ↓ PCA ↓ PC1 PC2

PC1 and PC2 are new features called principal components.

5. PCA Intuition

Imagine that the data points look approximately like this:

• • • • • • → Direction of maximum variation

PCA tries to find the direction where the data varies the most. That direction becomes the first principal component.

1 Find the direction with maximum variance.
2 This becomes PC1.
3 Find another perpendicular direction with the next highest variance.
4 This becomes PC2.

6. PCA Mathematical Intuition

The mathematical procedure behind PCA involves:

  1. Standardizing the data when appropriate
  2. Computing the covariance matrix
  3. Finding eigenvalues and eigenvectors
  4. Sorting components according to eigenvalues
  5. Projecting the original data onto the selected components

Standardization

z = (x - μ) / σ

where:

  • x = original value
  • μ = mean
  • σ = standard deviation

Explained Variance

Each principal component explains a certain amount of the total variance in the dataset.

Explained Variance Ratio = Variance of Component / Total Variance

For example:

11. Explained Variance Ratio

print(
    pca.explained_variance_ratio_
)

Suppose the output is: 

[0.997]

This means that approximately 99.7% of the variance is represented by the first principal component.

Key idea: A smaller number of dimensions can sometimes preserve most of the important variation in the original dataset.

15. How Many PCA Components Should We Keep?

Suppose PCA produces:

Component Explained Variance Cumulative
PC1 72% 72%
PC2 23% 95%
PC3 4% 99%
PC4 1% 100%

If we want approximately 95% explained variance, we could choose two components.

PC1 = 72% PC1 + PC2 = 95% PC1 + PC2 + PC3 = 99% PC1 + PC2 + PC3 + PC4 = 100%

17. LDA — Linear Discriminant Analysis

LDA stands for Linear Discriminant Analysis.

Unlike PCA, LDA is a supervised technique. It uses both:

X = Features y = Class Labels ↓ LDA ↓ Class-separating components
Main difference: PCA asks: "Where is the greatest variance?" LDA asks: "Where are the classes best separated?"

18. LDA Intuition

Suppose we have two classes:

Class A: ● ● ● ● Class B: ▲ ▲ ▲ ▲

LDA tries to find a projection where the classes become clearly separated.

Class A Class B ● ● ● ▲ ▲ ▲ ● ● ● ▲ ▲ ▲ ● ● ● ▲ ▲ ▲ <-------- Separation -------->

19. LDA Mathematical Intuition

LDA attempts to maximize between-class variance and minimize within-class variance.

maximize: Between-Class Variance / Within-Class Variance

In other words:

  • Classes should be far apart.
  • Samples belonging to the same class should be close together.

26. Kernel PCA

Kernel PCA is an extension of PCA that can capture nonlinear relationships.

Normal PCA Original Data ↓ Linear Transformation ↓ Principal Components Kernel PCA Original Data ↓ Kernel Function ↓ Higher-dimensional feature space ↓ PCA ↓ Kernel Principal Components

27. Why Do We Need Kernel PCA?

Consider circular data.

● ● ● ● ● ● ○ ○ ● ● ○ ○ ● ● ○ ○ ● ● ● ● ● ●

The structure is nonlinear. A simple linear projection may not represent the structure effectively.

28. Kernel Trick

Kernel PCA uses a kernel function to work with nonlinear relationships.

Common kernels include:

  • Linear
  • Polynomial
  • RBF
  • Sigmoid

The RBF kernel is especially common.

K(x, x') = exp(-γ ||x - x'||²)

The parameter gamma controls how local the influence of observations is.

35. Understanding Gamma in RBF Kernel PCA

Gamma is an important hyperparameter for the RBF kernel.

Gamma General Effect
Small gamma Smoother, broader influence
Medium gamma Moderate nonlinear transformation
Large gamma More local influence and more complex transformation

You should usually experiment with gamma rather than assuming one value works for every dataset.

38. When Should You Use Each?

PCA

  • No labels
  • Highly correlated features
  • Data compression
  • Visualization
  • Reduce computational cost

LDA

  • Labels are available
  • Classification problem
  • Class separation is important
  • Supervised dimensionality reduction

Kernel PCA

  • Nonlinear relationships
  • No labels required
  • Normal PCA is insufficient
  • Complex data structures

39. PCA + Machine Learning

Dimensionality reduction can be performed before a machine-learning classifier.

Original Data ↓ StandardScaler ↓ PCA ↓ Classifier ↓ Prediction 
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

X_train, X_test, y_train, y_test = train_test_split(
    X_scaled,
    y,
    test_size=0.2,
    random_state=42,
    stratify=y
)

pca = PCA(
    n_components=2
)

X_train_pca = pca.fit_transform(
    X_train
)

X_test_pca = pca.transform(
    X_test
)

model = LogisticRegression()

model.fit(
    X_train_pca,
    y_train
)

y_pred = model.predict(
    X_test_pca
)

accuracy = accuracy_score(
    y_test,
    y_pred
)

print(
    "Accuracy:",
    accuracy
)

40. Important: Avoid Data Leakage

Never do this: 
pca.fit_transform(X_test)
for your test data.

Instead: 

X_train_pca = pca.fit_transform(X_train)

X_test_pca = pca.transform(X_test)

The PCA transformation is learned only from the training data.

Rule: Fit preprocessing and dimensionality-reduction transformations on training data only. Then use transform() on validation and test data.

41. Better Approach: Scikit-learn Pipeline

A Pipeline keeps preprocessing and machine learning together. 

from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.linear_model import LogisticRegression

pipeline = Pipeline([

    (
        "scaler",
        StandardScaler()
    ),

    (
        "pca",
        PCA(n_components=2)
    ),

    (
        "classifier",
        LogisticRegression()
    )
])

pipeline.fit(
    X_train,
    y_train
)

y_pred = pipeline.predict(
    X_test
)

print(
    "Accuracy:",
    accuracy_score(
        y_test,
        y_pred
    )
)
Training Data ↓ StandardScaler ↓ PCA ↓ Logistic Regression ↓ Prediction

46. PCA Cheat Sheet

PCA | +-- Unsupervised | +-- Does not require y | +-- Linear | +-- Finds maximum variance | +-- Creates principal components | +-- PC1 = highest variance | +-- PC2 = second highest variance | +-- Components are orthogonal

47. LDA Cheat Sheet

LDA | +-- Supervised | +-- Requires X and y | +-- Linear | +-- Maximizes class separation | +-- Minimizes within-class variation | +-- Maximum components = classes - 1

48. Kernel PCA Cheat Sheet

Kernel PCA | +-- Unsupervised | +-- Does not require labels | +-- Can model nonlinear relationships | +-- Uses kernel functions | +-- Common kernel = RBF | +-- Important parameter = gamma

49. Which Technique Should I Choose?

Do you have labels? | +-------+-------+ | | NO YES | | ↓ ↓ PCA/KPCA LDA | Is the structure nonlinear? | +----+----+ | | NO YES | | ↓ ↓ PCA KPCA

50. Final Summary

PCA Finds directions of maximum variance.
LDA Finds directions that maximize class separation.
Kernel PCA Extends PCA so nonlinear structures can be represented.

The easiest way to remember:

PCA ↓ "What direction contains the most variation?" LDA ↓ "What direction separates my classes best?" Kernel PCA ↓ "What if the important structure is nonlinear?"
