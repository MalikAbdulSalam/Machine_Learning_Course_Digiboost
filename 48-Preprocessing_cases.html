Data Preprocessing Based on Column Types

Data preprocessing is one of the most important steps in Machine Learning. Raw data usually contains missing values, incorrect formats, duplicate records, outliers, and categorical data that cannot be directly used by machine learning algorithms.

Different types of columns require different preprocessing techniques. Understanding the type of each feature helps us apply the correct preprocessing method and improve the model's accuracy.

1. Numerical Columns (Continuous)

Definition:

Continuous numerical columns contain decimal or floating-point values. These values can take any number within a range.

Examples:

  • Age
  • Salary
  • Height
  • Weight
  • House Price
  • Temperature

Recommended Preprocessing:

  • Handle Missing Values using Mean or Median.
  • Detect and Remove Outliers.
  • Normalize or Standardize the data.
  • Apply Log Transformation if data is highly skewed.
  • Feature Scaling before training algorithms like KNN, SVM, and Neural Networks.

Example:

Age Salary
25 50000
30 62000
NaN 58000

2. Numerical Columns (Discrete)

Definition:

Discrete numerical columns contain countable values and usually do not contain decimal numbers.

Examples:

  • Number of Children
  • Quantity Sold
  • Number of Employees
  • Number of Orders

Recommended Preprocessing:

  • Fill missing values.
  • Check for invalid values.
  • Scale data if required.
  • Detect outliers.

3. Categorical Columns (Nominal)

Definition:

Nominal categorical data contains categories without any order.

Examples:

  • Gender
  • City
  • Country
  • Department
  • Color

Recommended Preprocessing:

  • Fill missing values using Mode.
  • Apply One-Hot Encoding.
  • Use Label Encoding only for binary categories.
  • Merge rare categories if necessary.

Example:

Gender City
Male Lahore
Female Karachi
Male Islamabad

4. Categorical Columns (Ordinal)

Definition:

Ordinal data has a meaningful order or ranking.

Examples:

  • Education Level
  • Customer Satisfaction
  • Low, Medium, High
  • Small, Medium, Large

Recommended Preprocessing:

  • Fill missing values.
  • Apply Ordinal Encoding.
  • Maintain the correct order while encoding.

Example Encoding:

Category Encoded Value
Low 1
Medium 2
High 3

5. Boolean Columns

Examples:

  • Purchased
  • Married
  • Paid
  • Yes / No
  • True / False

Recommended Preprocessing:

  • Convert Yes → 1
  • Convert No → 0
  • Convert True → 1
  • Convert False → 0

6. Date and Time Columns

Examples:

  • Date of Birth
  • Joining Date
  • Purchase Date
  • Transaction Time

Recommended Preprocessing:

  • Convert into datetime format.
  • Extract Year.
  • Extract Month.
  • Extract Day.
  • Extract Weekday.
  • Calculate Age.
  • Calculate Time Difference.

7. Text Columns

Examples:

  • Customer Reviews
  • Comments
  • Email Messages
  • Product Descriptions

Recommended Preprocessing:

  • Convert to lowercase.
  • Remove punctuation.
  • Remove stopwords.
  • Tokenization.
  • Stemming.
  • Lemmatization.
  • TF-IDF Vectorization.
  • Word Embeddings.

8. ID Columns

Examples:

  • Student ID
  • Customer ID
  • Order ID
  • Employee ID

Recommended Preprocessing:

  • Usually remove these columns.
  • Keep them only if they contain meaningful information.

9. Target Column

Classification Example:

Purchased
Yes
No

Regression Example:

House Price
250000
310000

Recommended Preprocessing:

  • Encode classification labels.
  • Do not scale unless required.
  • Never use target information while preprocessing features.

Complete Data Preprocessing Pipeline

  1. Understand the Dataset
  2. Identify Feature Types
  3. Handle Missing Values
  4. Remove Duplicate Records
  5. Correct Invalid Data
  6. Detect and Remove Outliers
  7. Encode Categorical Variables
  8. Scale Numerical Features
  9. Convert Date Columns
  10. Clean Text Columns
  11. Drop Unnecessary Columns
  12. Perform Feature Engineering
  13. Select Important Features
  14. Split Dataset into Training and Testing Sets
  15. Train Machine Learning Model
  16. Evaluate Model Performance

Conclusion

Selecting the correct preprocessing technique depends on the data type of each column. Numerical features usually require scaling and outlier handling, categorical features require encoding, date columns are converted into useful time-based features, text columns undergo Natural Language Processing (NLP), and identifier columns are generally removed. A well-preprocessed dataset leads to better machine learning performance, improved prediction accuracy, and faster model convergence.
