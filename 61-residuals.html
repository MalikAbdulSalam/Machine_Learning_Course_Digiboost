Why Do We Use Residuals in Machine Learning?

In Machine Learning, a residual tells us how far our model's prediction is from the actual value.

1. What is a Residual?

The residual is calculated using:

Residual = Actual − Predicted

Mathematically:

e = y − ŷ
  • y = Actual value
  • ŷ = Predicted value
  • e = Residual

2. Example of Residuals

Actual (y) Predicted (ŷ) Residual (y − ŷ)
100 90 10
150 160 -10
200 195 5
Example:

Actual value = 100
Predicted value = 90
Residual = 100 − 90 = 10
The model predicted 10 units too low.

3. Why Do We Use Residuals?

① To Measure Prediction Error

Residuals show us how much the model's predictions differ from the actual values.

  • Residual = 0 → Perfect prediction
  • Positive residual → Model predicted too low
  • Negative residual → Model predicted too high
  • Large residual → Large prediction error

② To Evaluate Regression Models

Several important regression metrics are calculated using residuals.

Mean Squared Error (MSE)

MSE = (1/n) × Σ(y − ŷ)²

Since:

Residual = y − ŷ

we can write:

MSE = (1/n) × Σ(Residual²)

Root Mean Squared Error (RMSE)

RMSE = √MSE

③ To Check Whether the Model Is Appropriate

We can plot residuals against predicted values. Ideally, residuals should be randomly scattered around zero.

Good residual pattern:

Residuals should generally look random rather than forming a clear pattern or curve.

Example:

•     •      •
─────────────────── 0
    •    •
•        •

If residuals show a clear pattern, it can indicate that the model is missing some relationship in the data.

4. Real-World Example: House Price Prediction

Actual house price: $300,000
Predicted house price: $280,000
Residual = 300,000 − 280,000
Residual = $20,000

Therefore, the model underestimated the house price by $20,000.

5. Important Concept

Think of residual as:

"How much did my model get wrong?"

6. Summary

  • Residual = Actual − Predicted
  • Residual measures prediction error.
  • Positive residual means the prediction was too low.
  • Negative residual means the prediction was too high.
  • MSE and RMSE are based on residuals.
  • Residual plots help us diagnose regression models.
  • Randomly scattered residuals around zero are generally desirable.
