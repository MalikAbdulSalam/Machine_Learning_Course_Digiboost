Clustering in Machine Learning

1. What is Clustering?

Clustering is an unsupervised machine learning technique used to group similar data points together.

In clustering, we do not provide predefined labels to the model. Instead, the algorithm automatically discovers groups or clusters in the data.

Simple Definition:

Clustering means automatically grouping similar data points together.

2. Why is Clustering Unsupervised Learning?

In supervised learning, we provide the model with input data and known output labels.

For example:

Age     Income      Label
20      20000       Low Income
45      60000       High Income
25      25000       Low Income
50      70000       High Income

In clustering, we don't provide the Label column. 

Age     Income
20      20000
45      60000
25      25000
50      70000

The algorithm discovers the groups by itself.

3. Real-World Example

Imagine a shopping company has information about its customers:

  • Age
  • Annual income
  • Spending score

A clustering algorithm can automatically divide customers into groups.

Cluster 1:
  • Young customers
  • Low income
  • Low spending
Cluster 2:
  • Middle-aged customers
  • High income
  • High spending

4. Common Clustering Algorithms

Algorithm Description
K-Means Divides data into a predefined number of clusters.
Hierarchical Clustering Creates a tree-like structure of clusters.
DBSCAN Groups data based on density and can identify outliers.
Gaussian Mixture Model Uses probability distributions to identify clusters.

5. K-Means Clustering

K-Means is one of the most popular clustering algorithms.

The letter K represents the number of clusters that we want to create.

For example: 

K = 2

Data → Cluster 1
     → Cluster 2

6. Simple K-Means Python Example

First, install the required libraries: 

pip install numpy scikit-learn matplotlib

Now create the dataset:

from sklearn.cluster import KMeans
import numpy as np

# Data
X = np.array([
    [1, 2],
    [2, 1],
    [2, 3],
    [8, 8],
    [9, 8],
    [8, 9]
])

# Create K-Means model
model = KMeans(
    n_clusters=2,
    random_state=42,
    n_init=10
)

# Train the model
model.fit(X)

# Get cluster labels
labels = model.labels_

print(labels)

7. Understanding the Output

The output may look like: 

[1 1 1 0 0 0]

This means that the algorithm found two groups. 

[1, 2] → Cluster 1
[2, 1] → Cluster 1
[2, 3] → Cluster 1

[8, 8] → Cluster 0
[9, 8] → Cluster 0
[8, 9] → Cluster 0
Important: Cluster numbers such as 0 and 1 do not have any special meaning. Cluster 0 could just as easily be called Cluster 1.

8. Visualizing Clusters

We can use Matplotlib to visualize the clusters. 

from sklearn.cluster import KMeans
import numpy as np
import matplotlib.pyplot as plt

X = np.array([
    [1, 2],
    [2, 1],
    [2, 3],
    [8, 8],
    [9, 8],
    [8, 9]
])

model = KMeans(
    n_clusters=2,
    random_state=42,
    n_init=10
)

model.fit(X)

labels = model.labels_

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=labels
)

plt.xlabel("X")
plt.ylabel("Y")

plt.title("K-Means Clustering")

plt.show()

9. What is a Centroid?

A centroid is the approximate center point of a cluster.

K-Means calculates the centroid of each cluster and assigns data points to the nearest centroid. 

print(model.cluster_centers_)

Example output: 

[[8.33 8.33]
 [1.67 2.00]]

10. Customer Clustering Example

Now let's use a more realistic machine learning example.

Suppose we have customer information containing:

  • Age
  • Income
import pandas as pd
from sklearn.cluster import KMeans

data = {
    "Age": [20, 22, 25, 45, 48, 50, 23, 27],

    "Income": [
        20000,
        22000,
        25000,
        60000,
        65000,
        70000,
        24000,
        28000
    ]
}

df = pd.DataFrame(data)

print(df)

11. Apply K-Means

model = KMeans(
    n_clusters=2,
    random_state=42,
    n_init=10
)

df["Cluster"] = model.fit_predict(
    df[["Age", "Income"]]
)

print(df)

13. Predict a New Customer's Cluster

Suppose a new customer has: 

Age = 24
Income = 26000

We can ask the trained model which cluster this customer belongs to. 

new_customer = [[24, 26000]]

cluster = model.predict(new_customer)

print(cluster)

Example output: 

[1]

This means the new customer belongs to Cluster 1.

14. Classification vs Clustering

Classification Clustering
Supervised learning Unsupervised learning
Uses labeled data Uses unlabeled data
Classes are known Groups are discovered
Example: Spam / Not Spam Example: Customer groups

15. Simple Difference

Classification

Input
  ↓
Machine Learning Model
  ↓
Known Class

Example:

Customer → High Income

Clustering

Input
  ↓
Machine Learning Model
  ↓
Automatically Discovered Group

Example:

Customer → Cluster 1

17. Advantages of Clustering

  • No labeled data is required.
  • Can discover hidden patterns.
  • Useful for exploratory data analysis.
  • Can help divide large datasets into meaningful groups.

18. Limitations of Clustering

  • Choosing the correct number of clusters can be difficult.
  • Some algorithms are sensitive to outliers.
  • Different algorithms can produce different results.
  • Feature scaling may be necessary.
  • Clusters are not always meaningful automatically; they require interpretation.

19. Key Points to Remember

  • Clustering is an unsupervised learning technique.
  • It groups similar data points together.
  • K-Means is one of the most popular clustering algorithms.
  • K represents the number of clusters.
  • K-Means uses centroids to represent clusters.
  • Clustering does not require predefined labels.
  • Cluster IDs such as 0, 1, and 2 are just identifiers.

20. Complete K-Means Example

Here is the complete example in one program: 

import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans

# Create data
X = np.array([
    [1, 2],
    [2, 1],
    [2, 3],
    [8, 8],
    [9, 8],
    [8, 9]
])

# Create K-Means model
model = KMeans(
    n_clusters=2,
    random_state=42,
    n_init=10
)

# Train and predict
labels = model.fit_predict(X)

# Print cluster labels
print("Cluster Labels:")
print(labels)

# Print centroids
print("\nCluster Centers:")
print(model.cluster_centers_)

# Visualize
plt.scatter(
    X[:, 0],
    X[:, 1],
    c=labels
)

# Plot centroids
centers = model.cluster_centers_

plt.scatter(
    centers[:, 0],
    centers[:, 1],
    marker="X",
    s=200
)

plt.xlabel("Feature 1")
plt.ylabel("Feature 2")

plt.title("K-Means Clustering")

plt.show()
