📊 R² vs Adjusted R²

Simple words + Python code  ·  No stats jargon, just what you actually need to know.

📈 R-Squared (R²)

“How much of Y is explained by my X’s?”

R² tells you the percentage of the variation in your outcome (Y) that your model explains.

R² = 0.80 → 80% of the data is explained by your model.

⚠️ Problem: Adding any variable (even useless ones) always increases or keeps R² the same.

📉 Adjusted R²

“Same as R², but honest.”

Adjusted R² penalizes you for adding extra variables. It only goes up if the new variable actually improves the model.

Adj R² = 0.76 → lower than R² if you added junk.

✅ Best for comparing models with different numbers of predictors.

⚔️ R² vs Adjusted R² – Side by Side

Feature R² Adjusted R²
What it measures % of variance explained % of variance explained with penalty
Goes up when adding any variable? ✅ Yes (or stays same) ❌ Only if variable is useful

Typical value Higher (optimistic) Lower or equal (realistic)

🐍 Python Example

Here’s how to calculate both – and see what happens when you add a useless variable.

# Import libraries
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# Data: house size (X) → price (Y)
X = np.array([500, 600, 700, 800, 900]).reshape(-1, 1)
y = np.array([100, 120, 150, 180, 200])

# Train model
model = LinearRegression()
model.fit(X, y)
y_pred = model.predict(X)

# R²
r2 = r2_score(y, y_pred)

# Adjusted R² (manual)
n = len(y) # observations
k = X.shape[1] # predictors
adj_r2 = 1 - (1 - r2) * (n - 1) / (n - k - 1)

print(f"R² = {r2:.4f}")
print(f"Adjusted R² = {adj_r2:.4f}")
Output:
R² = 0.9818
Adjusted R² = 0.9758

➕ Now add a useless variable (e.g., door color code):

X_useless = np.array([[500, 1],
               [600, 2],
               [700, 3],
               [800, 4],
               [900, 5]])

# R² still goes up (or stays) → 0.9818
# Adjusted R² goes DOWN → 0.9636 (penalized!)

✅ Adjusted R² drops because the useless variable doesn’t help – it penalizes the model.

🧠 Quick Takeaway

  • R² = “How much of Y is explained?” – always looks better with more variables.
  • Adjusted R² = Same, but honest – only improves if a variable really matters.
  • Always prefer Adjusted R² when comparing models with different numbers of features.
  • In Python, sklearn gives R² directly; Adjusted R² is one line of manual math.
