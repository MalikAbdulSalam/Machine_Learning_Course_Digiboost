1. Data Preprocessing for Clustering

Before applying clustering algorithms, we usually need to prepare the dataset.

Important preprocessing steps

  • Handle missing values
  • Remove duplicate records
  • Handle outliers
  • Convert categorical data into numerical data
  • Select useful features
  • Scale numerical features

6. Why Feature Scaling is Important

Clustering algorithms such as K-Means use distances between data points.

If one feature has a much larger numerical range than another, it can dominate the distance calculation.

Example: 
Age             → 20 - 60

Income          → 20,000 - 80,000

Spending Score  → 0 - 100
Income has a much larger numerical range.

7. StandardScaler

StandardScaler transforms the features so that they have approximately a mean of 0 and a standard deviation of 1. 

from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

X_scaled = scaler.fit_transform(X)

print(X_scaled)
Important:

Scaling is especially important for distance-based algorithms such as K-Means, DBSCAN, and K-Medoids.

8. MinMaxScaler

Another common scaling technique is MinMaxScaler.

It normally converts values to a range between 0 and 1. 

from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler()

X_scaled = scaler.fit_transform(X)

print(X_scaled)

StandardScaler vs MinMaxScaler

StandardScaler MinMaxScaler
Mean approximately 0 Values usually between 0 and 1
Standard deviation approximately 1 Preserves relative range
Useful for many ML algorithms Useful when a fixed range is desirable

10. Choosing the Number of Clusters

One of the most important questions in K-Means is:

How many clusters should we create?

Two commonly used techniques are:

  • Elbow Method
  • Silhouette Score

11. Elbow Method

The Elbow Method calculates the K-Means inertia for different numbers of clusters. 

from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

inertias = []

for k in range(2, 11):

    model = KMeans(
        n_clusters=k,
        random_state=42,
        n_init=10
    )

    model.fit(X_scaled)

    inertias.append(
        model.inertia_
    )


plt.plot(
    range(2, 11),
    inertias,
    marker="o"
)

plt.xlabel("Number of Clusters")
plt.ylabel("Inertia")

plt.title("Elbow Method")

plt.show()

Look for the point where the decrease in inertia begins to slow down significantly. This is called the elbow.

12. Silhouette Score

The Silhouette Score measures how well data points fit within their assigned clusters.

Its value generally ranges from -1 to 1.

Score Interpretation
Close to 1 Very good separation
Close to 0 Clusters overlap
Below 0 Possible incorrect assignments

Python Implementation

from sklearn.metrics import silhouette_score

score = silhouette_score(
    X_scaled,
    labels
)

print("Silhouette Score:", score)

13. Find the Best K Using Silhouette Score

from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

scores = []

for k in range(2, 11):

    model = KMeans(
        n_clusters=k,
        random_state=42,
        n_init=10
    )

    labels = model.fit_predict(
        X_scaled
    )

    score = silhouette_score(
        X_scaled,
        labels
    )

    scores.append(score)


for k, score in zip(
    range(2, 11),
    scores
):

    print(
        "K:",
        k,
        "Score:",
        score
    )

14. Calinski-Harabasz Score

The Calinski-Harabasz score evaluates the separation and compactness of clusters. 

from sklearn.metrics import calinski_harabasz_score

score = calinski_harabasz_score(
    X_scaled,
    labels
)

print(
    "Calinski-Harabasz Score:",
    score
)
Higher is generally better.

15. Davies-Bouldin Score

The Davies-Bouldin score measures similarity between clusters. 

from sklearn.metrics import davies_bouldin_score

score = davies_bouldin_score(
    X_scaled,
    labels
)

print(
    "Davies-Bouldin Score:",
    score
)
Lower is generally better.

16. PCA for Clustering Visualization

Real datasets can contain many features. We cannot easily visualize 10, 20, or 100 dimensions.

PCA can reduce the data to two dimensions for visualization. 

from sklearn.decomposition import PCA

pca = PCA(
    n_components=2
)

X_pca = pca.fit_transform(
    X_scaled
)

print(X_pca)

20. Compare Multiple Clustering Algorithms

We can apply several algorithms to the same dataset. 

from sklearn.cluster import KMeans
from sklearn.cluster import AgglomerativeClustering
from sklearn.cluster import DBSCAN
from sklearn.mixture import GaussianMixture

# K-Means

kmeans = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)

kmeans_labels = kmeans.fit_predict(
    X_scaled
)


# Hierarchical

hierarchical = AgglomerativeClustering(
    n_clusters=3
)

hierarchical_labels = hierarchical.fit_predict(
    X_scaled
)


# DBSCAN

dbscan = DBSCAN(
    eps=0.8,
    min_samples=5
)

dbscan_labels = dbscan.fit_predict(
    X_scaled
)


# GMM

gmm = GaussianMixture(
    n_components=3,
    random_state=42
)

gmm_labels = gmm.fit_predict(
    X_scaled
)


print("K-Means:")
print(kmeans_labels)

print("\nHierarchical:")
print(hierarchical_labels)

print("\nDBSCAN:")
print(dbscan_labels)

print("\nGMM:")
print(gmm_labels)

21. Evaluate Different Algorithms

from sklearn.metrics import silhouette_score

algorithms = {

    "K-Means":
        kmeans_labels,

    "Hierarchical":
        hierarchical_labels,

    "DBSCAN":
        dbscan_labels,

    "GMM":
        gmm_labels
}


for name, labels in algorithms.items():

    # Ignore DBSCAN if it creates only one cluster

    unique_labels = set(labels)

    if len(unique_labels) > 1:

        score = silhouette_score(
            X_scaled,
            labels
        )

        print(
            name,
            ":",
            score
        )

    else:

        print(
            name,
            ": Cannot calculate"
        )

25. How to Choose a Clustering Algorithm

Situation Possible Algorithm
Simple, well-separated clusters K-Means
Unknown number of clusters Mean Shift / DBSCAN / HDBSCAN
Outlier detection DBSCAN / HDBSCAN / OPTICS
Large dataset Mini-Batch K-Means / BIRCH
Overlapping clusters Gaussian Mixture Model
Hierarchical relationships Hierarchical Clustering
Partial membership Fuzzy C-Means
