Clustering Algorithms in Python

Clustering is an unsupervised machine learning technique used to automatically group similar data points together.

1. Types of Clustering

Algorithm Description
K-Means Divides data into a predefined number of clusters.
Hierarchical Clustering Creates a tree-like structure of clusters.
DBSCAN Groups data based on density and can identify outliers.
Gaussian Mixture Model Uses probability distributions to identify clusters.

4. K-Means Clustering

What is K-Means?

K-Means divides the dataset into a predefined number of clusters. The value of K represents the number of clusters.

Example:

K = 3 means that we want the algorithm to create three clusters.

Python Implementation

from sklearn.cluster import KMeans

# Create K-Means model
model = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)

# Train the model and get cluster labels
labels = model.fit_predict(X)

# Print labels
print("Cluster Labels:")
print(labels)

# Print cluster centers
print("\nCluster Centers:")
print(model.cluster_centers_)

Visualize K-Means

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=labels
)

# Get cluster centers
centers = model.cluster_centers_

# Plot centers
plt.scatter(
    centers[:, 0],
    centers[:, 1],
    marker="X",
    s=200
)

plt.xlabel("Feature 1")
plt.ylabel("Feature 2")

plt.title("K-Means Clustering")

plt.show()

5. Hierarchical Clustering

What is Hierarchical Clustering?

Hierarchical clustering creates a hierarchy of groups. The result can be visualized using a tree-like diagram called a dendrogram.

Unlike K-Means, we do not have to directly specify the cluster centers.

Python Implementation

from sklearn.cluster import AgglomerativeClustering

# Create model
model = AgglomerativeClustering(
    n_clusters=3
)

# Train and predict
labels = model.fit_predict(X)

print("Cluster Labels:")
print(labels)

Visualize Hierarchical Clustering

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=labels
)

plt.xlabel("Feature 1")
plt.ylabel("Feature 2")

plt.title("Hierarchical Clustering")

plt.show()

Create a Dendrogram

from scipy.cluster.hierarchy import dendrogram
from scipy.cluster.hierarchy import linkage

# Calculate linkage
linked = linkage(X, method="ward")

# Create dendrogram
plt.figure(figsize=(10, 6))

dendrogram(linked)

plt.title("Hierarchical Clustering Dendrogram")
plt.xlabel("Data Points")
plt.ylabel("Distance")

plt.show()

6. DBSCAN Clustering

What is DBSCAN?

DBSCAN stands for:

Density-Based Spatial Clustering of Applications with Noise

DBSCAN groups data points based on their density. It can also identify points that do not belong to any cluster.

These points are called outliers or noise.

Python Implementation

from sklearn.cluster import DBSCAN

# Create DBSCAN model
model = DBSCAN(
    eps=1.5,
    min_samples=2
)

# Train and predict
labels = model.fit_predict(X)

print("Cluster Labels:")
print(labels)

Understanding DBSCAN Labels

DBSCAN uses -1 to represent noise or outliers. 

0 → Cluster 0

1 → Cluster 1

2 → Cluster 2

-1 → Noise / Outlier

Visualize DBSCAN

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=labels
)

plt.xlabel("Feature 1")
plt.ylabel("Feature 2")

plt.title("DBSCAN Clustering")

plt.show()

7. Gaussian Mixture Model

What is Gaussian Mixture Model?

Gaussian Mixture Model, commonly called GMM, assumes that the data is generated from a mixture of several Gaussian probability distributions.

GMM is a probabilistic clustering algorithm.

Python Implementation

from sklearn.mixture import GaussianMixture

# Create GMM model
model = GaussianMixture(
    n_components=3,
    random_state=42
)

# Train and predict
labels = model.fit_predict(X)

print("Cluster Labels:")
print(labels)

Visualize GMM

plt.scatter(
    X[:, 0],
    X[:, 1],
    c=labels
)

plt.xlabel("Feature 1")
plt.ylabel("Feature 2")

plt.title("Gaussian Mixture Model")

plt.show()

10. Real-World Example: Customer Segmentation

Clustering can be used to divide customers based on their age and annual income. 

import pandas as pd
from sklearn.cluster import KMeans

# Customer dataset
data = {
    "Age": [20, 22, 25, 45, 48, 50, 23, 27],
    "Income": [
        20000,
        22000,
        25000,
        60000,
        65000,
        70000,
        24000,
        28000
    ]
}

df = pd.DataFrame(data)

print(df)


# Create model
model = KMeans(
    n_clusters=2,
    random_state=42,
    n_init=10
)


# Create clusters
df["Cluster"] = model.fit_predict(
    df[["Age", "Income"]]
)


print("\nCustomers with Clusters:")
print(df)

11. Predict a New Customer

After training the model, we can assign a new customer to an existing cluster. 

# New customer
new_customer = [[24, 26000]]

# Predict cluster
cluster = model.predict(new_customer)

print("New Customer Cluster:")
print(cluster)

12. Important Concepts

  • K-Means: Best when you know approximately how many groups you want.
  • Hierarchical: Useful when you want to study the hierarchy of groups.
  • DBSCAN: Useful when clusters have irregular shapes and when detecting outliers is important.
  • GMM: Useful when clusters overlap and a probabilistic assignment is useful.
