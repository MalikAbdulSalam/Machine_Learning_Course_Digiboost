Top 10 Classification Models in Machine Learning

After splitting the dataset and applying feature scaling, you can train different classification algorithms. The training process remains almost identical. Only the classifier changes.

Workflow

  1. Load Dataset
  2. Create DataFrame
  3. Select Features (X) and Target (y)
  4. Split Training and Testing Data
  5. Scale Features
  6. Create Classification Model
  7. Train the Model
  8. Predict Test Data
  9. Calculate Accuracy
  10. Predict New Data

Python Code (Compare All Classifiers)

Python 
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import (
    RandomForestClassifier,
    GradientBoostingClassifier,
    AdaBoostClassifier,
    ExtraTreesClassifier
)
from sklearn.svm import SVC
from sklearn.naive_bayes import GaussianNB
from sklearn.neighbors import KNeighborsClassifier
from sklearn.neural_network import MLPClassifier
from sklearn.metrics import accuracy_score

models = {

    "Logistic Regression":
        LogisticRegression(),

    "KNN":
        KNeighborsClassifier(n_neighbors=3),

    "Decision Tree":
        DecisionTreeClassifier(random_state=42),

    "Random Forest":
        RandomForestClassifier(random_state=42),

    "Support Vector Machine":
        SVC(kernel="linear"),

    "Gaussian Naive Bayes":
        GaussianNB(),

    "Gradient Boosting":
        GradientBoostingClassifier(random_state=42),

    "AdaBoost":
        AdaBoostClassifier(random_state=42),

    "Extra Trees":
        ExtraTreesClassifier(random_state=42),

    "Multi Layer Perceptron":
        MLPClassifier(max_iter=1000,
                      random_state=42)
}

for name, model in models.items():

    model.fit(X_train, y_train)

    y_pred = model.predict(X_test)

    accuracy = accuracy_score(y_test, y_pred)

    print(f"{name:30} Accuracy : {accuracy:.2f}")

Explanation

Step Description
Create Model Select the machine learning classifier.
model.fit() Train the classifier using the training dataset.
model.predict() Predict labels for the testing dataset.
accuracy_score() Calculate the prediction accuracy.
Loop Automatically trains and evaluates all classifiers.

Advantages of Using a Dictionary

  • Write less code.
  • Easy to compare multiple algorithms.
  • Add or remove classifiers quickly.
  • Suitable for experimentation and model selection.
  • Professional coding practice.
